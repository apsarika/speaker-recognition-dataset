# speaker-recognition-dataset
Custom Hindi speech dataset for Speaker Recognition using ML, DL, and One-Shot Learning. Contains 100 speakers with 3 audio samples each: one fixed sentence (“Mera naam ___ hai aur yeh mera voice sample hai”) and two random Hindi sentences. Dataset was preprocessed before model training.

https://www.kaggle.com/datasets/apsarikasharma/speaker-recognition-dataset
